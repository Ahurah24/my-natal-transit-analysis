# ربات ترید ارزینجا — نسخه ویندوز

رابط وب محلی با **Python + FastAPI + React**. سرویس‌ها فقط روی `127.0.0.1` گوش می‌دهند و داشبورد در مرورگر باز می‌شود.

## پیش‌نیازها
- Windows 10/11 x64
- Python 3.11 یا جدیدتر
- Node.js LTS و npm

## نصب
1. پوشه `arzinja_trading_bot_windows` را دریافت کن.
2. PowerShell را در همین پوشه باز کن.
3. در صورت نیاز فقط برای همین نشست اجرای اسکریپت را مجاز کن:
   `Set-ExecutionPolicy -Scope Process Bypass`
4. اجرا کن: `./install_windows.ps1`

## اجرا
روی `start_windows.bat` دوبار کلیک کن. داشبورد در این آدرس باز می‌شود:
`http://127.0.0.1:5173`

API محلی:
- سلامت: `http://127.0.0.1:8000/api/health`
- وضعیت: `http://127.0.0.1:8000/api/status`

## امنیت و وضعیت فعلی
- حالت پیش‌فرض Paper است.
- `LIVE_TRADING_ENABLED=false` است و در این مرحله هیچ مسیر سفارش واقعی پیاده‌سازی نشده.
- کلیدهای API فقط در فایل محلی `.env` قرار می‌گیرند؛ هرگز آن را در GitHub قرار نده.
- رابط فعلاً موجودی، قیمت یا سود فرضی نشان نمی‌دهد.
- اتصال ارزینجا تا زمان تأیید مستندات جاری، آدرس پایه، احراز هویت و مسیر کندل‌ها عمداً متصل نشده است.
- بک‌تست معتبر باید فقط از داده تاریخی واقعی صرافی استفاده کند و کارمزد، اسپرد و لغزش قیمت را لحاظ کند.

## مراحل بعدی
1. تأیید API رسمی و تست read-only بازار.
2. انتقال دقیق استراتژی موجود، بدون تغییر پنهانی قوانین آن.
3. بک‌تست با داده واقعی و گزارش هزینه‌ها.
4. Paper Trading و ثبت معاملات شبیه‌سازی‌شده.
5. آزمون ویندوز و بررسی امنیتی پیش از هرگونه قابلیت معامله واقعی.
